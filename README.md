# Resonance

安装：`npm ci`

本地启动：`npm run dev`

类型检查 / 构建：`npm run typecheck` / `npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:8015。

## 多轨伴奏

- 导入多段音频（可多选），各轨按时间线偏移同时播放；不同采样率/时长混用由
  AudioContext 自动重采样，所有轨道共用同一条传输时钟（绝对时间锚点 `origin`），
  暂停后继续、移动播放位置、循环都整体重排，轨道之间不会越播越不同步。
- 每轨独立音量、静音（M）、独奏（S）、淡入/淡出。独奏临时覆盖静音选择，
  取消独奏后恢复原先的静音状态；所有增益切换走 `setTargetAtTime` 平滑，无爆音。
- 演出中拖动片段可预听新位置：预听只接扬声器，不进入分析/录制母线，确认前录制
  继续收旧混音；松开确认提交新偏移，Esc 或取消则预听淡出、不产生爆音、不改偏移。
- 内存预算（设备内存约 1/4，封顶 512MB）：解码后 PCM 超预算时明确拒绝新增轨道并
  保留当前演出，绝不降低已在播轨道的音质。
- 舞台可视化与录制都由最终总混音母线驱动，录制片段保存的是当时实际听到的总混音。
